# 📚 NotesWise  



---

## 🚀 Overview  

**NotesWise** is an **AI-powered study companion** designed to make learning smarter and more interactive.  
It combines **AI models** with a powerful **Django + PostgreSQL backend** to provide tools like summarization, grammar checking, chatbot Q&A, quiz crafting, flashcards, diagram and text editing, and a built-in storage system.

## ✨ Features  

### 🤖 AI-Powered Tools  
- **Summarization** – Generate concise summaries of long texts.  
- **Grammar Check** – AI-powered grammar and style corrections.  
- **Chatbot Q&A** – Interactive chatbot for study assistance.  
- **Quiz Crafting** – Automatic quiz generation from notes.  

### 📝 Study Tools  
- **Text Editor** – Write, edit, and format notes.  
- **Diagram Editor** – Create flowcharts and diagrams.  
- **Flashcard Editor** – Build and revise flashcards.  
- **Storage System** – Save, manage, and organize notes securely.
